# Terra Nova components (for Paper)

Standalone copy of the **Design system** section from the Atlas case study on
angelowellens.eu: the live bento of Terra Nova components. The portfolio is
untouched; this folder is a copy to load into Paper and experiment with.

Preview: `python3 -m http.server 5192` here → http://localhost:5192

## Files

| File | What | Source in the portfolio (`_site/`) |
|---|---|---|
| `index.html` | Markup for all 8 tiles | `projects/atlas/atlas.html` lines 1388–1714 (phone fallback image dropped) |
| `css/terra-nova.css` | All component styles | `projects/atlas/atlas.html` lines 527–1033 |
| `js/terra-nova.js` | Interactions (`initDsBento`), vanilla JS | `js/angelo.js` lines 2959–3933 (site-only click guard removed) |
| `assets/ds/` | Icons, avatars, company + entity logos, Figma thumb | `projects/atlas/assets/ds/` |

## Tokens

Defined as custom properties on `.dsb` at the top of `css/terra-nova.css`:
neutrals `--n0`…`--n900`, `--brand` #4538D6 (+ `-50`, `-100`), status colours
(green, red, blue, yellow + `-50` tints), `--radius-xxs`…`--radius-xl`
(4–32px), `--spacing-xxs`…`--spacing-6x` (4–120px). Type styles: `.t-h1`–`.t-h4`
(Inter 56/40/32/24).

## Tiles → selectors

| Tile | Selector |
|---|---|
| Colour & type styles | `[data-tile="found"]` |
| Terra Nova in Figma | `[data-tile="figma"]` |
| Bulk | `[data-tile="bulk"]` |
| Icons | `[data-tile="icons"]` |
| Side Navigation | `[data-tile="side"]` |
| Table | `[data-tile="table"]` |
| Select | `[data-tile="select"]` |
| Card | `[data-tile="card"]` |

Tiles are absolutely positioned on a 1474 × 2032 canvas (Figma pixels);
`initDsBento` scales it to fit. Some tile content is generated by the JS
(table rows, guides, autoplay cursor), so a static HTML import shows only
what's in the markup until the script runs.

## Re-sync

`python3 build_from_site.py` re-copies from the portfolio (overwrites index.html, css/, js/, assets/ds/; leaves other files alone).
